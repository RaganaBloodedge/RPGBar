========================================
  RPGBar 联机跑团 · 使用指南（先看这个）
========================================

这是一款「多人联机文字跑团」游戏：AI 当主持人（DM），
你和朋友一人开一台设备，连进来一起玩文字冒险。

（想确认自己拿到的是哪一版？看启动窗口第一行的 vX.Y.Z，
  网页顶栏也会显示同样的版本号。各版本更新内容见项目里的 CHANGELOG.md。）

------------------------------------------------
一、你需要准备什么
------------------------------------------------
1. 一台 Windows 电脑（当「主机」，跑游戏服务器）。
2. 一个浏览器（Chrome / Edge 都行，用来玩）。
3. 和朋友连同一个 WiFi（最简单），或不同网络（见「四点五、异地怎么连」）。

------------------------------------------------
二、第一步：主机启动服务器
------------------------------------------------
1. 解压这个 zip 包。
2. 双击里面的  RPGBarServer.exe
3. 会弹出一个黑色窗口，稍等几秒，出现类似这样的内容：

       [RPGBar] 服务器监听 0.0.0.0:8000
       [RPGBar] 本机访问: http://127.0.0.1:8000
       [RPGBar] 把下面任意一行发给朋友（局域网 / 虚拟局域网均可）：
       [RPGBar]     http://192.168.x.x:8000    [以太网]  ← 本机主网卡
       [RPGBar]     http://10.126.x.x:8000     [EasyTier]

   这里会把本机「所有」网卡的地址都列出来 —— 装了虚拟局域网工具的话，
   虚拟网卡那一行也会出现。挑一行发给朋友即可：
   同一个 WiFi 发「以太网」那行；异地就发「EasyTier」那行。

   ⚠ 如果 Windows 弹出蓝色「Windows 已保护你的电脑」：
      点「更多信息」→「仍要运行」。
   ⚠ 如果弹出「Windows 防火墙」提示：勾选「专用网络」→ 点「允许访问」。

   这个黑色窗口不要关，关掉服务器就停了。

------------------------------------------------
三、第二步：主机自己先进游戏（建房）
------------------------------------------------
1. 主机打开浏览器，地址栏输入： http://127.0.0.1:8000
2. 输入你的名字（如「小明」），选一个职业。
3. 「房间码」那一栏【留空】，直接建房。
4. 「开局剧本」那一栏，选你们这局想跑哪个剧本
   （只有留空房间码自己建房时才可选；选定后这局所有玩家都用它）。
5. 点「进入游戏」。
6. 进入后，看页面右上角「房间」后面的 5 位码（比如 ABC12），
   这就是你们房间的房号，把它告诉朋友。

------------------------------------------------
四、第三步：朋友加入
------------------------------------------------
1. 朋友打开浏览器，输入主机给的地址：
       http://192.168.x.x:8000（同 WiFi）或 http://10.126.x.x:8000（虚拟局域网）
2. 输入朋友自己的名字 + 职业。
3. 房间码那一栏，填主机告诉他的 5 位房号（如 ABC12）。
   （「开局剧本」这一栏会自动置灰 —— 剧本由房主建房时就选定了，
     你连进去会自动同步，不用自己选。）
4. 点「进入游戏」，就进到同一个房间了。
   （多人同理，每个人都填同一个房号）

------------------------------------------------
四点五、异地怎么连？（虚拟局域网，推荐）
------------------------------------------------
你们不在同一个 WiFi 也能一起玩，而且**不需要把电脑暴露到公网**。

最简单的办法：给双方装一个「虚拟局域网」工具，把两台电脑"接"进同一个
私密网络里 —— 之后就跟在同一个 WiFi 下一样了。

推荐工具（挑一个，**双方装同一个**）：

  ● EasyTier   —— 国产开源，有国内节点，速度快     https://easytier.cn
  ● 蒲公英     —— 国产，图形界面友好
  ● Tailscale  —— 国外，安装最简单，但国内有时会绕远路变慢

以 EasyTier 为例：

1. 主机和朋友都下载安装 EasyTier。
2. 双方用**同一个网络名 + 同一个密码**启动（这就是你们的"私密网络"）。
3. 启动后，主机的服务器窗口会自动列出虚拟网卡的地址，形如：
       [EasyTier]  http://10.126.x.x:8000
   （网页里也看得到：加入页展开「联机地址」，或游戏内「⚙ 设置 → 联机地址」，
     点一下即可复制。）
4. 把这行 http://10.126.x.x:8000 发给朋友，让他用浏览器打开，填房号进来。
5. 之后每次开黑，只要双方的 EasyTier 都在运行就行。

好处：外人进不来这个虚拟网络（比直接暴露公网安全），也不用买服务器。

------------------------------------------------
五、怎么玩
------------------------------------------------
- 底部输入框写你的行动，回车发送。
  例如：说服老周 / 调查挂毯 / 推开铁门进入门厅
- 点「助手建议」按钮，会弹出几个当前可做的行动，点击即可发送。
- 点右侧「掷 d20」可以自由掷骰（检定由 DM 自动投）。
- 左侧是剧情旁白，右侧是队友名单、已获得的线索，以及「在场人物」。
- 所有人的行动、骰子结果都会实时同步给全房间的人。

------------------------------------------------
五点二、想用 AI 大模型当 DM？（可选）
------------------------------------------------
不接模型也能完整玩（默认就是），接上会更活。

点顶栏的「⚙ 设置」按钮，会打开一个设置面板，
上半部分是【剧本】，下半部分是【模型】：

  主机 DM · 大模型      —— 只有房主能改，全房间共用
                          推进剧情、投骰判定、扮演 NPC
  主机小助手 · 小模型   —— 只有房主能改，全房间共用
                          给剧本外的路人 NPC 现场生成人物小传、
                          算反应权重（默认指向 127.0.0.1:8081）
  玩家小助手 · 小模型   —— 每个人配自己的
                          只读场景，给你行动建议

每个槽位三选一：

  ● 关闭        —— 不接，走内置剧本逻辑（推荐先这么玩）
  ● 云 API      —— 选 DeepSeek / OpenAI / 智谱 预设，
                   填入你自己的 API Key
  ● 本地模型    —— 选 llama.cpp / Ollama / LM Studio 预设，
                   地址指向你自己电脑上跑的模型，不需要 Key

填完点「测试连接」看看通不通（会顺便告诉你这个模型
支不支持工具调用，不支持也能用，只是稍简单些），
再点「保存并连接」即可，立刻生效，下次进来也记得住。

你的 API Key 只存在你自己这台电脑的浏览器里，
不会发给别人，也不会显示在服务器上。

------------------------------------------------
五点三、剧本与「本房间」（可选，房主操作）
------------------------------------------------
剧本有两层，别搞混：

  ● 本房间剧本 —— 建房时在加入页「开局剧本」里选定，开局后**固定不变**。
    朋友连进来会自动同步它，全房间始终跑同一份剧本、同一套 Agent 提示词。
    在「⚙ 设置 → 本房间」里能看到这局用的剧本、切片清单，以及同步下来的 prompt。
  ● 活动剧本   —— 给**之后新开的房间**当默认值，不影响正在玩的对局。

服务器会把剧本文件读进来、自动切好片，再据此生成一段"剧本设定"给 AI
—— 这部分不用你操心。

在「⚙ 设置 → 剧本」里可以：

- 看到所有可用的剧本（默认两个：《古堡秘宝》《蛇王墓·第一层》）。
- 点其中一个 → 点「读取并切片」，就能看到它被切成了几片，
  以及给 AI 的剧本设定长什么样。
- 点「设为活动剧本」切换（只有房主能点，只影响之后新开的房间）。
- 不想放文件也行：展开「或直接粘贴剧本内容」，
  把剧本文字粘进去，会自动识别格式。

（剧本文件要放在 exe 同目录的 scripts 文件夹里。）

------------------------------------------------
五点四、NPC 是有血有肉的
------------------------------------------------
剧本里点名的主角 NPC 自带人设；但你在街上随便碰到的路人、被你搭话的
店小二、被你揍了一顿的挑夫，剧本里没写他们 —— 以前他们就是"没有灵魂的
空壳"，现在不是了。

- 当你第一次和这类路人互动时，主机会【临场给他补一份人物小传】：
  他是谁、什么脾气、说话什么腔调、想要什么、怕什么。
  之后 DM 就按这份小传扮演他。
- 如果你做的是有后果的事（打人、恐吓、帮忙、给钱……），还会再算一次
  【他大概率会怎么反应】：老实人被打多半想息事宁人，暴徒多半会还手。
  ⚠ 具体会不会动手、会不会报警，仍然由服务端的骰子决定 ——
  AI 只负责给一个"可能性区间"，落点由骰子抽。所以你没法靠哄 AI 来
  让 NPC 按你想要的方式反应。
- 右侧「在场人物」面板会列出你已经遇到过的 NPC（名字 · 身份）。
  鼠标停在名字上，还能看到别人给他起的外号（你叫他"周老头"，
  系统照样认得那个"老周"）。

这一整块由「主机小助手」负责（见五点二）。它**没接模型也能用**：
系统内置了六类原型（平民 / 暴徒 / 商人 / 卫兵 / 学者 / 权贵），
不接 AI 时按原型兜底，行为一样稳定。

另外，NPC 和你的交往记录、他对你的好感，都只留在 NPC 自己那儿，
不会塞进 DM 的剧情记忆里 —— 这样 DM 记的是"剧情"，而不是一堆杂事，
剧情不容易跑偏。

------------------------------------------------
五点五、玩到一半才来的人也能加入
------------------------------------------------
不需要等人齐才开局，也不需要重开房间——任何时候填上房号进来就行。

新玩家加入时：

1. 所有人都会看到 DM 写的一段旁白，让新角色自然地登场，
   并顺带复述此前发生了什么（所以剧情是连贯的，不突兀）。
2. 新玩家的聊天区会多出一张【故事回顾】卡片，写着：
      行程：之前走过哪些场景
      线索：队伍已经拿到的关键线索
      最近动态：最近几条行动记录
   这张卡片只有新玩家自己看得到，不会打扰其他人。

所以：主机先开着玩，朋友什么时候上线，什么时候填房号加入即可。
（注：如果主机把黑色窗口关了，进度就没了，需要重开一局。）

------------------------------------------------
六、常见问题
------------------------------------------------
Q1：朋友打不开那个地址？
   A：确认两人连的是【同一个 WiFi】；确认主机的黑色窗口还开着；
      确认防火墙允许了访问。

Q2：我们不在同一个网络（异地），怎么办？
   A：推荐用「虚拟局域网」（见「四点五」）：双方装 EasyTier / 蒲公英 /
      Tailscale，加入同一个私密网络，然后用主机窗口里 [虚拟网卡] 那行
      地址（形如 http://10.126.x.x:8000）即可，安全又免费。
      也可以把主机的 8000 端口做内网穿透（cpolar / frp）映射到公网。

Q3：关了窗口是不是就结束了？
   A：对，服务器就靠那个黑色窗口运行。想一直玩就保持窗口开着。

Q4：能换成 AI 实时写剧情吗？
   A：可以。点网页顶栏的「⚙ 设置」，在【模型】部分接入
      （见第五节第二段），云 API 或本机跑的本地模型都行。
      也可以把 config.example.json 复制成 config.json 放在
      exe 同目录，填好里面的 models 三段（dm / assistant / advisor），
      重启服务器生效。
      配上之后，中途加入的旁白与回顾也会由 AI 来写，更自然。

Q5：能换成别的剧本吗？
   A：可以。建房时在加入页的「开局剧本」里直接选就行（决定这一局）。
      想加新剧本：把剧本文件放进 exe 同目录的 scripts 文件夹，
      然后在「⚙ 设置 → 剧本」里点「读取并切片」看看效果，
      房主点「设为活动剧本」即可设为默认（之后新开的房间生效）。
      也支持直接粘贴剧本文字，不用放文件。

Q6：朋友中途掉线了，重新进来会怎样？
   A：直接重新填房号进来即可。系统会当他"中途加入"，
      给他一段带入旁白和回顾卡片，信息不会丢。

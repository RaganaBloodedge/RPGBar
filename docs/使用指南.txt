========================================
  RPGBar 联机跑团 · 使用指南（先看这个）
========================================

这是一款「多人联机文字跑团」游戏：AI 当主持人（DM），
你和朋友一人开一台设备，连进来一起玩文字冒险。

（想确认自己拿到的是哪一版？看启动窗口第一行的 vX.Y.Z，
  网页顶栏也会显示同样的版本号。各版本更新内容见项目里的 CHANGELOG.md。）

------------------------------------------------
一、你需要准备什么
------------------------------------------------
1. 一台 Windows 电脑（当「主机」，跑游戏服务器）。
2. 一个浏览器（Chrome / Edge 都行，用来玩）。
3. 和朋友连同一个 WiFi（最简单），或不同网络（见文末「异地怎么办」）。

------------------------------------------------
二、第一步：主机启动服务器
------------------------------------------------
1. 解压这个 zip 包。
2. 双击里面的  RPGBarServer.exe
3. 会弹出一个黑色窗口，稍等几秒，出现类似这样的内容：

       [RPGBar] 服务器监听 0.0.0.0:8000
       [RPGBar] 本机访问: http://127.0.0.1:8000
       [RPGBar] 局域网访问（发给朋友）: http://192.168.x.x:8000

   记住最后那行「局域网访问」的地址（就是 http://192.168.x.x:8000），
   待会儿要发给朋友。

   ⚠ 如果 Windows 弹出蓝色「Windows 已保护你的电脑」：
      点「更多信息」→「仍要运行」。
   ⚠ 如果弹出「Windows 防火墙」提示：勾选「专用网络」→ 点「允许访问」。

   这个黑色窗口不要关，关掉服务器就停了。

------------------------------------------------
三、第二步：主机自己先进游戏（建房）
------------------------------------------------
1. 主机打开浏览器，地址栏输入： http://127.0.0.1:8000
2. 输入你的名字（如「小明」），选一个职业，点「进入古堡」。
3. 房间码那一栏【留空】，直接进入。
4. 进入后，看页面右上角「房间」后面的 5 位码（比如 ABC12），
   这就是你们房间的房号，把它告诉朋友。

------------------------------------------------
四、第三步：朋友加入
------------------------------------------------
1. 朋友打开浏览器，输入主机给的「局域网访问」地址：
       http://192.168.x.x:8000
2. 输入朋友自己的名字 + 职业。
3. 房间码那一栏，填主机告诉他的 5 位房号（如 ABC12）。
4. 点「进入古堡」，就进到同一个房间了。
   （多人同理，每个人都填同一个房号）

------------------------------------------------
五、怎么玩
------------------------------------------------
- 底部输入框写你的行动，回车发送。
  例如：说服老周 / 调查挂毯 / 推开铁门进入门厅
- 点「助手建议」按钮，会弹出几个当前可做的行动，点击即可发送。
- 点右侧「掷 d20」可以自由掷骰（检定由 DM 自动投）。
- 左侧是剧情旁白，右侧是队友名单和已获得的线索。
- 所有人的行动、骰子结果都会实时同步给全房间的人。

------------------------------------------------
五点五、玩到一半才来的人也能加入
------------------------------------------------
不需要等人齐才开局，也不需要重开房间——任何时候填上房号进来就行。

新玩家加入时：

1. 所有人都会看到 DM 写的一段旁白，让新角色自然地登场，
   并顺带复述此前发生了什么（所以剧情是连贯的，不突兀）。
2. 新玩家的聊天区会多出一张【故事回顾】卡片，写着：
      行程：之前走过哪些场景
      线索：队伍已经拿到的关键线索
      最近动态：最近几条行动记录
   这张卡片只有新玩家自己看得到，不会打扰其他人。

所以：主机先开着玩，朋友什么时候上线，什么时候填房号加入即可。
（注：如果主机把黑色窗口关了，进度就没了，需要重开一局。）

------------------------------------------------
六、常见问题
------------------------------------------------
Q1：朋友打不开那个地址？
   A：确认两人连的是【同一个 WiFi】；确认主机的黑色窗口还开着；
      确认防火墙允许了访问。

Q2：我们不在同一个网络（异地），怎么办？
   A：需要「内网穿透」让两台电脑互通。最简单的是装一个
      ZeroTier 或 Tailscale（两个人都装，加入同一个虚拟网络），
      然后用里面给的虚拟 IP 代替 192.168 地址即可。
      或者用 cpolar / frp 把主机的 8000 端口映射到公网。

Q3：关了窗口是不是就结束了？
   A：对，服务器就靠那个黑色窗口运行。想一直玩就保持窗口开着。

Q4：能换成 AI 实时写剧情吗？
   A：默认是「剧本模式」（按内置剧本《古堡秘宝》推进）。
      如果想接 AI 大模型，可在 exe 同目录放一个 config.json
      （内容参考包里的 config.example.json 填入 API key）。
      配上之后，中途加入的旁白与回顾也会由 AI 来写，更自然。

Q5：朋友中途掉线了，重新进来会怎样？
   A：直接重新填房号进来即可。系统会当他"中途加入"，
      给他一段带入旁白和回顾卡片，信息不会丢。

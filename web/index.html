              （尚未连入房间）

              剧本

              服务端读取剧本文件后自动切片，并生成排在 System prompt 之后的 次级 prompt（世界观、语气、切片索引）。System prompt 只管三个 Agent 各自的职责。

              模型

              三个 Agent 都走标准 OpenAI 兼容接口，填 云 API 的 Key，或指向 本地模型 （llama.cpp / Ollama / LM Studio）。DM（大模型）推进剧情；两个小助手跑小模型即可。

              内置引擎

              用自带的 RPGBarEngine 在服务器进程内直接跑模型，不需要任何外部服务 （云 API / llama.cpp / Ollama）。启用后三个 Agent 都改走它。由房主设置，全房间共用。

              联机地址

              这是本机所有可被朋友访问的地址（含 EasyTier / Tailscale 等虚拟网卡）。 点一下即复制，发给朋友就能连进来。
